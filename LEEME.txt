========================================================
  CLASIFICADOR PDF - INSTRUCCIONES DE INSTALACIÓN
========================================================

¡Gracias por descargar ClasificadorPDF!

Este archivo contiene instrucciones importantes para instalar
y ejecutar la aplicación correctamente.


INSTALACIÓN RÁPIDA (3 PASOS)
========================================================

1. EXTRAER EL ARCHIVO ZIP
   - Haz clic derecho en el archivo ZIP descargado
   - Selecciona "Extraer todo..." o "Extract all..."
   - Elige una ubicación (ej: Escritorio, Documentos)
   - Haz clic en "Extraer"

2. DESBLOQUEAR LA APLICACIÓN
   - Abre la carpeta donde extrajiste los archivos
   - Busca el archivo: DesbloquearApp.bat
   - Haz DOBLE CLIC en DesbloquearApp.bat
   - Espera a que termine el proceso

3. ¡LISTO!
   - La aplicación se abrirá automáticamente
   - Ya puedes usar ClasificadorPDF


¿POR QUÉ NECESITO DESBLOQUEAR LA APLICACIÓN?
========================================================

Windows marca los archivos descargados de Internet como
"potencialmente peligrosos" por seguridad. Esto puede
causar el error:

  "Windows no puede acceder al dispositivo, ruta de
   acceso o archivo especificado"

El script DesbloquearApp.bat elimina esta marca de
seguridad de forma segura, permitiendo que la aplicación
se ejecute normalmente.

IMPORTANTE: Solo necesitas hacer esto UNA VEZ después
de descargar la aplicación.


SOLUCIÓN DE PROBLEMAS
========================================================

PROBLEMA: "Windows no puede acceder al dispositivo"
SOLUCIÓN: Ejecuta DesbloquearApp.bat (ver paso 2 arriba)

PROBLEMA: Windows Defender bloquea la aplicación
SOLUCIÓN: 
  1. Abre Windows Defender
  2. Ve a "Protección contra virus y amenazas"
  3. Haz clic en "Administrar configuración"
  4. Desplázate hasta "Exclusiones"
  5. Agrega la carpeta de ClasificadorPDF

PROBLEMA: Necesito permisos de administrador
SOLUCIÓN: 
  1. Ejecuta RepararAcceso.bat en lugar de DesbloquearApp.bat
  2. Haz clic derecho en RepararAcceso.bat
  3. Selecciona "Ejecutar como administrador"

PROBLEMA: La aplicación no se actualiza
SOLUCIÓN:
  - La aplicación verifica actualizaciones automáticamente
  - Ve a Ajustes > Reinstalar Aplicación para forzar
  - O descarga la última versión manualmente


ACTUALIZACIONES AUTOMÁTICAS
========================================================

ClasificadorPDF incluye un sistema de actualización
automática. Cuando haya una nueva versión disponible:

1. La aplicación te notificará al iniciar
2. Haz clic en "Actualizar" para descargar
3. El proceso es automático y seguro
4. La aplicación se reiniciará con la nueva versión

NOTA: Las actualizaciones descargadas automáticamente
      NO requieren volver a ejecutar DesbloquearApp.bat
